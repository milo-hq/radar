# 防止卖方宣传成为需求证据

X 实测中，旧报告将动作捕捉开发者自述解释为独立买方需求，并出现单条原文无法支持的普遍性和市场价值判断。

提取、报告、审核升级到 v3；对直接使用者抱怨、供给方描述、不可追溯的二手反馈作明确区分。代码在提取入口和报告输入处拦截明确宣传/转述模式，保存被排除的引文和原因。规则是保守启发式，不是完整语义分类器；其他宣传仍可能漏过，有实际工具使用场景的开发者请求应保留。发布校验补充普遍性和市场价值夸大语句。

同样18条X材料的对照重跑保留原报告，新建轮次并标注历史原文重分析。旧版3候选，新版0候选；新版模型仍选中一次动作捕捉卖方原文，被程序过滤。不能把结果变少解释为市场不存在。

提供 scripts/reanalyze-scan.ts，对已完成轮次的已存原文建立独立分析任务（v3幂等），不重新爬取、不改写原文或旧轮次。空结果报告根据实际分析数量说明证据不足，展示程序过滤原因，不再误称采集为空。
