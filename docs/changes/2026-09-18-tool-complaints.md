# 工具抱怨与未满足功能发现

用户已确认以已有工具的抱怨、替代、缺失功能和具体本地化缺口为中心，不再泛搜创业主题。

- Reddit 四个社区改为近一年定向搜索，固定同社区同站点边界。搜索卡片支持普通链接；标题仅用于排序，宣传降权，不作为需求证明。
- 自动规划、提取、报告、审核提示升级为 v2，保留 v1 以便审计。具体场景下未实现的功能请求可以成为探索候选；泛许愿、宣传和已解决问题不保留。
- 输出沿用现有字段，要求明确参考工具、受阻任务、绕行方式、待核实差异、单人实现边界和先验证后开发的条件。
- 本次没有提高报告的五项上限，也没有实现跨轮机会池；这是搜索与提取方向调整，不能承诺机会数量增加。

验证：数据库回归、搜索DOM夹具、MV3扩展端到端、类型/构建，以及可选真实模型评估脚本 scripts/eval-tool-complaints.ts（需要模型配置，会产生API调用）。

部署后需要用户在Chrome扩展管理页重新加载本地扩展；后端无法自动替换运行中的扩展脚本。
