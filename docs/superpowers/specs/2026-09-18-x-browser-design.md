# X 公开工具痛点采集

用户要求加入 X，并沿用工具抱怨、替代、未实现功能的发现目标。

复用现有浏览器配对、租约、回放去重、原文库和自动分析流程。内部 transport 暂沿用 reddit_browser 以兼容已安装客户端，source=x 决定独立解析器；不迁移旧任务身份。新增 sources.x 和 x_enabled 能力位。旧客户端心跳默认关闭 X 能力，不能领取 X 任务。

Chrome 扩展新增可选 x.com 网站权限，通过用户点击“启用 X 访问”请求。默认关闭，现有 Reddit 权限不变。每轮四组工具需求搜索，每组最多20条帖子、6次页面读取，只在扩展自己的搜索页读取渲染内容。遇登录、验证、页面不识别或权限撤销暂停。原帖ID、URL和作者严格匹配，引用帖正文不拼接到作者正文；缺少正文跳过。所有快照标记上下文不完整，长文、引用和回复未展开，不把搜索命中当需求证明。

设置页提供独立X任务入口，自动发现保存本轮X加入/跳过原因。原文库与比较标注X来源。沿用中文翻译和模型抽取，不增加私信、发帖、互动或Cookie访问。

验证：身份校验、旧客户端能力隔离、回放去重、X入库进入分析、真实Chromium DOM及隔离MV3端到端（网络夹具）、真实登录搜索页可读性。启用新增权限及重新加载扩展由用户完成后，才能验证用户会话中的自动采集。
