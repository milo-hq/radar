# 自动网页爬取扩展

用户要求用爬虫扩大来源。复用Python引擎，新增浏览器渲染+正文提取+持久化URL队列的网页采集模块；自动发现流程无需输入网站或主题。

1. 先实测公开网站与robots，选择可访问的产品目录、用户社区等站点预设；拒绝把网站名称当接入完成。
2. Python POST /crawl {siteId}：只接受站点预设，不接受任意URL；从种子页发现同站相关链接，按持久化frontier逐批处理。HTTP优先，动态页面用Playwright Chromium，Trafilatura正文抽取；保留原文URL、站点、页面类型、采集方式与上下文限制。
3. SQLite持久化frontier/cache放独立Docker卷，只存爬取缓存/访问记录，不取代Postgres业务数据。每站限速、robots、请求上限、错误重试/退避；不绕登录、验证码或付费墙。失败和跳过可见。
4. 每轮规划后追加每站一个DISCOVER_TOPIC payload.source=web,siteId任务；复用原文幂等入库与模型流水线。网页任务独立，不把同一站点对4个主题重复爬取。
5. 前端展示爬虫各站状态、真实页面数、缓存/渲染/发现链接统计；优先显示机会结果。
6. 测试链接过滤/正文提取/动态渲染/robots/缓存/去重/重试/安全限制，真实至少多个域名完成采集，Docker全流程验证。
