# shadcn 工作台重做
用户授权：整体界面和功能重做，历史使用正常可维护表格。
1. 引入官方 shadcn 组件和 Tailwind v4，统一浅色管理台主题。
2. 历史表格服务端分页/搜索/状态/排序/总数，保留按轮次详情查看。
3. 工作台导航和页面结构统一；机会、参考产品、原文、采集任务表格化并保留业务操作；表单/弹窗统一组件。
4. 自动发现移除大幅宣传区域，改成工具栏、历史表格、当前详情和结构化结果。
5. 类型、API、浏览器覆盖桌面手机、实际 Docker 验证，部署并推送。
